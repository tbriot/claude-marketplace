# tbriot — Claude Code marketplace

Personal marketplace of Claude Code plugins.

## Installation

```
/plugin marketplace add tbriot/claude-marketplace
/plugin install git-flow@tbriot
```

## Plugins

### `git-flow`

Git workflow: branch, commits, push and merge request (squash).

- `/git-flow:ship [description]` — creates a `<type>/<name>` branch, makes small Conventional Commits, pushes, and opens (or updates) the MR/PR.
